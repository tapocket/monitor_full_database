➕ Управление базой мониторов и брендов (Динамический пересчет)

Все счетчики брендов и моделей в портале вычисляются динамически из массива DB.catalog. При добавлении нового монитора (или нового бренда) либо удалении существующей модели шапка, вкладки, выпадающий фильтр брендов и сводная таблица по брендам пересчитываются автоматически.

🔄 Центр онлайн-цен, автоподхват prices_live.json и фоновый парсер

Портал поддерживает 3 режима актуализации цен для всех моделей с прямыми ссылками:
  • Автоподхват prices_live.json: при открытии портал автоматически проверяет наличие файла prices_live.json в одной папке с HTML и обновляет цены, пошлину РФ и бейджи выгоды.
  • Прямой онлайн-запрос из браузера: проверка витрин через CORS-прокси либо кнопка 🔄 По ссылке у любой конкретной модели.
  • Импорт / Экспорт JSON-слепка цен: загрузка свежего файла prices_live.json в 1 клик.
Готовый CRON-шаблон GitHub Actions (.github/workflows/update_prices.yml) для автоматического обновления prices_live.json каждые 6 часов:
name: Auto-Update Monitor Prices (prices_live.json)
on:
 schedule:
 - cron: '0 */6 * * *'
 workflow_dispatch:
jobs:
 sync-prices:
 runs-on: ubuntu-latest
 steps:
 - uses: actions/checkout@v4
 - uses: actions/setup-python@v5
 with: { python-version: '3.11' }
 - name: Fetch live store prices & recalculate duty
 run: python3 scripts/update_prices_live.py
 - name: Commit updated prices_live.json
 run: |
 git config user.name "monitor-price-bot"
 git config user.email "bot@users.noreply.github.com"
 git add prices_live.json
 git diff --quiet && git diff --staged --quiet || (git commit -m "chore: update live monitor prices" && git push)

📲 Установка портала как PWA-приложения (Офлайн в ПВЗ)

В портал встроен Web App Manifest и автономный Service Worker. Вы можете установить базу на главный экран смартфона или рабочий стол ПК, чтобы в пункте выдачи (ПВЗ DNS / Ozon / WB / Ситилинк) без интернета открывать коды матриц, комбинации сервисных меню и полноэкранный тестер битых пикселей.
1. На смартфоне (Android Chrome / iOS Safari): откройте меню браузера и нажмите «Добавить на главный экран» / «Установить приложение».
2. На ПК (Chrome / Edge / Яндекс Браузер): нажмите на значок установки ⊕ справа в адресной строке или кнопку ниже.
