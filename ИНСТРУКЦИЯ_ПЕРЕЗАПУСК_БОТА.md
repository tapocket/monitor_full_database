# Инструкция: как перезапустить Telegram-бота после выключения или перезагрузки ПК

После выключения компьютера Telegram-бот останавливается, потому что работает локально на вашем ПК. Ниже — два способа быстро запустить его снова: **в 1 двойной клик** (рекомендуется) и **вручную через терминал**.

---

## Способ 1. Запуск в 1 двойной клик (настроить 1 раз — пользоваться всегда)

1. Откройте папку вашего проекта:
   `C:\Users\TAPOCKET\Documents\monitor_full_database\bot\`
2. Создайте внутри папки `bot` обычный текстовый файл с названием **`.env`** (без `.txt` в конце; или откройте Блокнот → Сохранить как → Тип файла: *Все файлы* → Имя: `.env`).
3. Напишите внутри ровно одну строчку со своим токеном от `@BotFather` (без кавычек и лишних пробелов) и сохраните:
   ```text
   TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
   ```
   *(Файл `.env` уже добавлен в `.gitignore`, поэтому GitHub Desktop никогда не загрузит ваш секретный токен в публичный репозиторий.)*
4. Теперь каждый раз после включения компьютера просто откройте папку `bot` и сделайте **двойной клик по файлу `ЗАПУСК_БОТА.bat`** (его ярлык можно вынести прямо на Рабочий стол).
5. Откроется окно с надписью `Telegram bot ... started (2763 models)...` — сверните его (не закрывайте), бот работает!

---

## Способ 2. Ручной запуск через терминал Windows 11

1. Откройте папку `C:\Users\TAPOCKET\Documents\monitor_full_database` в Проводнике Windows.
2. Кликните **правой кнопкой мыши** по пустому месту внутри папки → выберите **«Открыть в терминале»**.
3. Вставьте две строчки (подставив свой токен внутри кавычек) и нажмите **Enter**:
   ```powershell
   $env:TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER"
   python bot/telegram_bot.py
   ```
4. Когда появится `Telegram bot ... started (2763 models)...` — бот снова в сети.

---

## Как остановить бота

* Нажмите в окне терминала **`Ctrl + C`** или просто закройте окно.

## Если захочется, чтобы бот работал 24/7 при выключенном ПК

* Загрузите репозиторий на любой минимальный российский VPS (Ubuntu + Docker) и выполните в папке `bot`:
  ```bash
  TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER" docker compose up -d
  ```
  После этого компьютер можно выключать — бот будет работать круглосуточно.
